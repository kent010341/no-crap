# 簡化重述

使用者呼叫這個 skill，代表他看不懂你剛剛的回答（或他附帶的文字、網址、檔案），沒有充分理解。請簡化重述，讓他看得懂。

什麼都沒附帶時，處理你上一則回答。附帶的文字是他的補充要求，照辦。

簡化只動表達，不動事實：指令、數字、限定條件照舊，不新增原文沒有的建議。
